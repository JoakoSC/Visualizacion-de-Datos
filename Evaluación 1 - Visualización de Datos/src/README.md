# Proyecto de Visualización de Datos - StreamView Analytics (EP1)

## Descripción
Solución de analítica visual y dashboard interactivo desarrollado en Streamlit para analizar el engagement, retención y comportamiento de los usuarios de StreamView Analytics.

## Requisitos previos
- Python 3.11+
- Librerías: `pip install streamlit pandas plotly openpyxl`

## Instrucciones de ejecución
1. Clonar o extraer el proyecto.
2. Ejecutar el archivo `Ejecutar_App.bat` o usar la terminal:
   ```powershell
   python -m streamlit run dashboard/app.py
